# bilingual-product-posters

一套用于制作侘寂美学中英文商品海报的 Codex Skill。它依据真实商品图片、品牌资料和可验证参数，为中文与英文市场分别规划构图、人物关系和信息层级，输出安静、克制、自然且具时间感的电商视觉。

## 核心能力

- 制作中文无人物静物商品海报。
- 制作英文人物互动海报，支持简约大字版和详细信息版。
- 根据商品与品牌选择温润自然、清冷石灰或深色手作等侘寂方向。
- 使用自然材质、低饱和色彩、柔和定向光和不对称留白建立视觉氛围。
- 保持商品外形、颜色、结构、Logo、规格、价格与交易条件准确。
- 完成商品抠图、场景融合、接触阴影、环境反射和确定性排版。
- 在完整尺寸和手机缩略图下检查真实性、可读性与整体一致性。

## 适用场景

适用于以下需求：

- 侘寂、wabi-sabi、自然系、原生材质或质朴风格的商品海报。
- 希望画面呈现极简、复古、安静和低促销感的电商视觉。
- 需要分别制作中文与英文版本，而不是直接在同一底图上换字。
- 需要减少霓虹、科技特效、玻璃卡片和密集参数表的商品宣传设计。

不适用于普通换字、白底商品主图、炫彩科技风、纯参数 UI 图或直接照搬其他品牌版式。

## 默认输出

| 项目 | 默认设置 |
| --- | --- |
| 输出语言 | 中文和英文 |
| 中文版本 | 无人物静物完整版 |
| 英文版本 | 人物互动详细信息版 |
| 侘寂方向 | 温润自然 |
| 画面比例 | 竖版 4:5 |
| 输出尺寸 | 1600 × 2000 PNG |

用户可以指定仅中文、仅英文、两种英文版本、其他侘寂方向或不同画面尺寸。

## 输入资料

建议提供以下内容：

- 商品图片及附件图片。
- 品牌 Logo 和品牌规范。
- 完整商品名称、型号和宣传标题。
- 已核实的卖点、规格、价格和币种。
- 活动日期、优惠条件和行动提示。
- 使用场景、投放平台、语言和尺寸要求。

示例图与参考海报只用于理解设计方法，不会被当作当前商品的事实来源。未提供的价格、参数、认证、功效或产地信息不会被自行编造。

## 输出分支

### 中文完整商品海报

采用无人物的编辑式静物摄影，以真实商品、自然材质和完整中文信息为核心。通常包含完整商品名、主题标题、两至三个重点卖点，以及用户已提供的交易信息。

### 英文简约大字版

采用克制的人物与商品互动，只保留一个编辑式英文标题，以及包含品牌和完整商品名的小型识别信息组。默认不加入卖点列表、价格、活动日期或行动按钮。

### 英文详细信息版

在可信的人物互动基础上，呈现完整商品名、核心卖点、规格以及用户提供的价格、日期、条件和行动提示。信息依靠字号、间距与对齐建立层级，不使用密集卡片墙。

## 设计原则

设计按以下优先级作出判断：

1. 商品真实性。
2. 信息准确性与可读性。
3. 构图与留白。
4. 材质与光线。
5. 装饰细节。

侘寂在本 Skill 中是一套视觉取舍，而不是米色滤镜或日式符号集合。不完美感只作用于背景、纸张、器物、光影和图形表现，不会让新品看起来破损、脏旧或二手。

## 工作流程

1. 整理商品事实，标记信息来源、语言、必显内容和不可改写内容。
2. 确认输出语言、英文版本、侘寂方向、尺寸和交付数量。
3. 规划材质、色板、光线、构图和信息层级。
4. 精细抠出真实商品，并为标题、商品名和必填信息预留安全区域。
5. 生成无文字场景底图，合成商品并重建接触阴影、环境反射与综合色温。
6. 使用可编辑方式加入文字、数字、Logo 和必要图标。
7. 在完整尺寸与手机缩略图下完成质量检查。
8. 导出最终 PNG，并保留后续编辑所需的中间素材。

## 输出文件

建议使用以下命名方式，避免覆盖已有版本：

- `product_zh.png`：中文完整商品海报。
- `product_en_minimal.png`：英文简约大字版。
- `product_en_detailed.png`：英文详细信息版。

除最终 PNG 外，建议同时保留透明商品图、无字底图、可编辑排版或合成脚本、字体说明和最终生成提示词。

## 质量标准

- 三秒内可以识别商品、完整商品名和主要主题。
- 商品结构、颜色、Logo、附件和比例与参考资料一致。
- 产品边缘干净，没有白边、漏抠或原图矩形。
- 场景具有可信的承托面、光源、接触阴影和环境反射。
- 画面有自然材质与时间感，但保持干净、高级和清晰。
- 中文版本不出现人物；英文版本的人物互动真实、安静且符合产品使用逻辑。
- 所有价格、日期、单位、限定词和功能描述均与原始资料一致。

## 注意事项

- 英文版本不代表美元市场，不会自动换汇。
- 中英文海报分别构图，不通过同一底图直接替换文字生成。
- 最终文字、数字、Logo 和功能图标应使用可编辑、确定性的方式排版。
- 除非商品与品牌资料明确需要，否则不主动加入竹子、樱花、日式门窗、茶道器具、书法或印章等文化符号。
- 讨论、安装或修改本 Skill 本身不会触发图片生成；只有明确提出制作海报时才执行视觉生成流程。
