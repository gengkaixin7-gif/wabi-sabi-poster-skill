# 侘寂艺术指导

## 不是一种滤镜

侘寂海报通过克制、不对称、自然材料和时间留下的细微痕迹建立情绪。它不是统一的米色滤镜，也不是把画面做旧、做脏、做暗。每个选择都要能解释商品：材质回应触感，光线回应使用场景，留白回应信息优先级。

## 四个视觉支点

### 1. 不完美但准确

- 允许手工边缘、轻微印刷错位、非绝对居中和表面细小差异。
- 商品本体、Logo、数字和文字保持准确、完整、清晰。不完美只存在于背景、道具、纸张和图形表现。
- 不添加裂痕、锈蚀、掉漆、污渍或二手痕迹，除非它们本来就存在或用户明确要求。

### 2. 自然但不布景过度

每张选择 2–3 种主材质，并明确它们与商品的关系：

| 材质 | 适合表达 | 风险 |
| --- | --- | --- |
| 石灰墙、矿物涂料 | 安静、漫反射、手作肌理 | 太灰会让商品失去轮廓 |
| 素陶、黏土、砂岩 | 温润、触觉、日常器物感 | 容易误导为手工或天然材质商品 |
| 亚麻、棉布、旧纸 | 柔软、轻盈、生活痕迹 | 纹理过强会干扰文字 |
| 旧木、软木 | 温度、时间、居家尺度 | 深色木纹容易显杂乱 |
| 氧化金属、未抛光石材 | 克制、耐久、结构感 | 不要让新品看起来锈坏 |
| 枯枝、种荚、干草 | 季节、尺度、自然节奏 | 少量使用，避免“森系摆拍” |

### 3. 安静但有层级

- 主体、标题、商品名、卖点、交易信息按优先级逐级减弱。
- 允许大面积空墙、桌面或纸张，但用光斑、阴影、纹理方向和不等距留白维持平衡。
- 不对称构图需要视觉回衡：较重的产品可以由小号文字、边缘道具或光区平衡，而不是硬拉回正中。
- 一张图只用一种主要形状语言。若商品圆润，文字分区可更柔和；若商品硬朗，使用直线和清楚基线。

### 4. 复古但不复刻年代

- 通过低饱和色、胶片颗粒、轻微褪色、网点或压印质感建立年代感。
- 颗粒细小、均匀且服从景深；不要覆盖 Logo、商品结构和小字。
- 可借鉴旧杂志的留白、窄栏、页码感和边注，但不照搬特定海报、品牌或艺术家的版式。

## 色板

先从商品本色、品牌色和使用场景取样，再选择一个倾向：

- 温润自然：骨白、燕麦、黏土、旧木、炭黑，适合家居、器物、饮品与个护。
- 清冷石灰：灰白、雾灰、砂岩、石墨、低饱和苔绿，适合数码、金属与极简工具。
- 深色手作：烟褐、铁锈棕、深橄榄、米灰、旧金属，适合户外、皮具与耐用品。

不要机械套用。商品与背景色接近时，通过明度、冷暖、接触阴影和轮廓反射分离，而不是给商品加发光描边。

## 光线

- 默认使用单侧窗光、阴天漫射光或带柔化布的大面积棚灯。
- 明确主光方位、色温、阴影方向和软硬度；暗部保留材质信息。
- 允许局部阳光、窗格影或轻微尘埃，但每种效果都要在产品和场景上产生一致结果。
- 避免双侧霓虹、蓝紫边缘光、强烈体积光、舞台聚光和无方向泛光。

## 字体与版式

- 中文优先选择可读宋体/衬线与中性无衬线；英文优先温润 serif 或 humanist sans。全图不超过两种字体家族。
- 利用字号、字重、行距、字距和对齐建立层级。局部可以有窄栏、边注、编号和细分隔线。
- 轻微压印、漏墨和错版效果只能用于大标题或装饰字，且不能改变字符识别。
- 避免假书法、印章、满屏竖排、所有字母大写加宽字距、密集圆角卡片和 UI 仪表盘。

## 提示词结构

生成无文字底图时按以下顺序说明：

1. 商品真实性：外形、比例、颜色、材质、不可改变的结构。
2. 摄影概念：安静静物或人物互动，情绪与使用语境。
3. 构图：相机高度、焦段、主体位置、负空间和安全文字区。
4. 材质：仅列 2–3 种并说明前中后景位置。
5. 光线：方向、软硬、色温、阴影和环境反射。
6. 色板：产品本色、背景色、一个强调色及对比关系。
7. 质感：轻微胶片颗粒、印刷或纸张感，保持产品清晰。
8. 禁止项：可读文字、伪造 Logo、错误结构、额外配件、重度做旧、日式符号、霓虹科技特效、卡片墙、杂乱道具。

## 快速判断

如果去掉米色和颗粒后画面便失去“侘寂感”，说明设计只停留在滤镜层。合格的方案即使转成灰度，也应通过材质、光线、间距、不对称和克制信息保持安静而稳定。
