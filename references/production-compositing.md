# 产品抠图、场景融合与质量门槛

## 1. 取得可合成的真实产品

1. 查看全部商品照片，确认主产品、附件和真实连接关系。
2. 将产品从白底或原场景中精细分离，保留透明部件、孔洞、线缆、把手、反光边、Logo 和细小结构。
3. 分别放在深色与浅色检查底上确认无白边、背景残影、漏抠和整块原图矩形。
4. 新视角必须逐项核对比例、零件、接口、开孔、颜色和 Logo。无法可靠重建时退回真实角度，通过摆放、裁切与光线建立变化。

## 2. 先规划场景再合成

- 确定承托面、相机高度、透视、产品占比和负空间，再选择 2–3 种自然材质。
- 为标题、完整商品名、核心卖点和必填交易信息预留安全区域。不要用大圆角白卡包住未抠出的商品照片。
- 道具需要有尺度、用途或材质上的理由。装饰不足不是问题，道具过多才会削弱侘寂的安静感。

## 3. 重建共同光照

- 确定主光的位置、大小、色温和强度，再匹配产品本体的亮暗、高光与环境综合色。
- 按接触关系添加接触阴影、投影和必要的环境遮挡。反光表面可有克制倒影，方向必须正确。
- 白色产品用冷暖微差、边缘反射和局部暗面保留体积；深色产品用受控轮廓反射读出结构，不用发光描边。
- 商品要保持最清晰。背景颗粒、纸纹和褪色不能跨过产品边缘成为统一滤镜。

## 4. 确定性排版

- 最终文字、数字、Logo 和功能图标使用可编辑矢量或确定性排版完成，不依赖图像模型随机生成。
- 图标只在详细版确实改善扫描时使用，保持单色、统一线宽与视觉重量。不得把装饰图形伪装成认证标志。
- 文字和产品轮廓之间保留可见呼吸空间；商品底部、人物手部和 Logo 不得被标题、渐变或价格覆盖。

## 5. 导出门槛

| 关口 | 通过标准 | 失败时处理 |
| --- | --- | --- |
| 抠图 | 产品边缘干净透明，无原背景矩形 | 重新抠图与修边 |
| 真实性 | 外形、部件、颜色和 Logo 与参考一致 | 修正或退回可信角度 |
| 场景融合 | 有可信支撑、接触阴影、综合色温和环境反射 | 重做合成与光照 |
| 侘寂质感 | 材质有理由、色彩克制、颗粒不损害清晰度 | 减少道具与滤镜，重做材质层 |
| 信息 | 完整商品名和必填事实可读，数字准确 | 补全并重排 |
| 中英分支 | 中文无人物；英文互动真实且符合版本密度 | 修正人物或信息层级 |

全部通过后导出最终 PNG，并保留透明商品、无字底图、可编辑排版、字体说明和最终提示词。
